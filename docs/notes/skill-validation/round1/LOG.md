## SKILL.md 最需要补充或澄清的点

1. **`sort` 的 key 能返回什么类型**：文档只说“key 是把元素映射为比较键的函数”，例子全是 `-x` 这种数字。字符串键能不能用（我用了 `fn(e) => e.word`，可以），能不能返回数组做多级排序（如 `[-e.count, e.word]`），都没写。“次数降序、同次数按字母升序”这种需求非常常见，建议直接给出推荐写法：“先按次键排序，再按主键排序（稳定）”，或者说明是否支持数组键。另外“降序可用 `fn(x) => -x` 后再处理”这句话含义模糊，字符串降序怎么做也没说。
2. **`reverse` 作用于字符串时返回什么**：表格写 `reverse(c)` “返回新数组”，参数名是 `c`（集合，暗示可以是字符串），那么 `reverse("abc")` 返回 `"cba"` 还是 `["c","b","a"]`？判断回文这种场景很常见。我为了稳妥写成了 `join(reverse(split(s, "")), "")`，没有验证直接 `reverse(s)` 的行为。建议明确。
3. **`match` 能否匹配字符串字面量**：第 2 节写“字面量”，例子全是数字。我写了 `match op { "+" => ..., "/" => ..., _ => nil }` 并且能用，但文档没明说。建议在示例中加一个字符串分支。同时，`match` 分支之间用逗号分隔、最后一项允许尾逗号，这一点从例子能看出来，但没有文字说明。
4. **保留字列表**：题目要求写 `transfer(from, to, amount)`，`from`、`to`、`in`、`self` 这类词是否是关键字文档没有列出（文档只提了“中英文关键字”，没给清单，也没给中文关键字对照表，只在坑里出现了 `如果`）。`from` / `to` 实际可以当参数名。建议附一张英文 ↔ 中文关键字对照表，同时就是保留字清单。
5. **值的打印格式**：`print` 浮点数时 `6.0/3` 显示为 `2.0`（我是实测才知道的）；数组里的字符串打印出来带不带引号、`nil` 打印成什么、结构体打印格式（第 2 节有一个 `Point(x: 4, y: 5)` 例子）都只能靠猜。输出格式对“结果是否正确”影响很大，建议在第 3 节 `print`/`str` 一行补一句规则。
