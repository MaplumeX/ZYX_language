# 统一调用语法：`a.f(b)` 在 `a` 没有方法 `f` 时等价于 `f(a, b)`

`x.name(args)` 先查 `x` 所属结构体的 `impl` 方法，查不到再查当前作用域内名为 `name` 的函数并以 `x` 作第一个参数调用。这样内置函数无需按类型挂方法（`arr.push(1)` 就是 `push(arr, 1)`），用户函数也能写成方法链，并与管道运算符 `x |> f(b)` 的"第一个参数"约定一致。

## Consequences

- 内置函数一律设计成"操作对象作第一个参数"，以便同时支持函数、方法、管道三种写法。
- 结构体字段中存放的函数不能写 `x.f()` 调用，需写 `(x.f)()`，因为 `.f(...)` 总是按方法/函数解析。
- 方法查找失败时的报错是 `NameError`，而非"字段不存在"。
