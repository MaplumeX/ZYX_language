# 先做树遍历解释器，再升级为字节码虚拟机，两个后端并存

功能完整优先于性能，所以第一版用 AST 树遍历执行，并在解析后做一遍槽位解析，把变量提前定位为槽位编号，避免运行时查哈希表。测试全部通过后再把 AST 编译为字节码，由栈式虚拟机执行。

树遍历后端不删除：两个后端共用同一个前端（词法、语法、槽位解析），通过命令行参数选择。测试集在两个后端上都要通过，树遍历版作为参考实现，用于差分测试；性能报告同时对比树遍历版、虚拟机版和 CPython。

## Considered Options

- **直接做字节码虚拟机**：没有重复开发，但前期进度慢，出错时难以判断是语义理解错了还是编译/虚拟机写错了。
- **只做树遍历**：开发量最小，但预计比 CPython 慢 1 到 3 倍，性能部分只能做原因分析。
