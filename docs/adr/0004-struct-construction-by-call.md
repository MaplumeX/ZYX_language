# 结构体用调用语法构造，而不是花括号字面量

结构体实例写作 `Point(1, 2)` 或 `Point(x: 1, y: 2)`，结构体名本身就是构造函数，而不是 Rust/Go 式的 `Point { x: 1, y: 2 }`。原因是 ZYX 的 `if`/`while`/`for`/`match` 条件不加括号、后接花括号块，`if p == Point { x: 1 } { ... }` 这类写法在解析时有歧义；Rust 靠"条件位置禁止结构体字面量"的特例规则解决，调用语法则从根本上消除了歧义，也让构造与普通函数调用保持一致。

## Consequences

- 具名参数 `name: expr` 只对结构体构造有效，普通函数调用使用具名参数报 `TypeError`。
- 按位置和按字段名两种构造方式不能在同一次调用中混用。
