# v1 不提供异常捕获，任何错误都终止程序

课程要求的功能中不含异常处理，而 `try`/`catch` 需要在树遍历和字节码两个后端中都实现栈展开，成本不低。v1 中所有错误（包括 `assert` 失败和 `error()`）都会打印 `[line 行:列] 类别: 信息` 并以非零退出码结束；错误类别和格式在设计时就固定下来，为以后加入捕获机制留出余地。

## Consequences

- 黑盒测试中的错误用例只能"一个文件测一个错误"，通过比对标准错误输出和退出码判断。
- 应用程序需要自行校验用户输入，为此提供 `parse_int(s)`，解析失败时返回 `nil` 而不是报错。
